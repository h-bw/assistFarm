---
name: ui-redesign
description: Improve the layout, styling, and interaction of a frontend page while preserving business logic.
---

# Goal
Refactor the page UI without breaking existing functionality.

# Steps
1. Summarize current UI issues.
2. Propose a minimal redesign plan.
3. Reuse existing UI library components where possible.
4. Preserve API bindings, events, and route logic.
5. Keep styles scoped when possible.
6. After editing, summarize changed files and visible improvements.

# Rules
- Do not rename API fields unless necessary.
- Do not remove business logic.
- Avoid introducing new dependencies unless clearly needed.
- Prefer clean spacing, typography, and visual hierarchy.
